Wat heb ik geleerd

Mijn naam is Julius Gerth, en voor mijn herkansing Frontend Development mocht ik student-assistent zijn bij het vak Web is voor iedereen.

Door Julius

Mijn rol als student-assistent

Mijn rol was om te helpen tijdens deepdives die werden gegeven door Vasilis en Sanne. Tijdens deze deepdives was ik beschikbaar voor vragen die te maken hadden met opdrachten die ze moesten maken of vragen die ze hadden over de website die ze moesten maken.

Mijn ervaring

Tijdens het helpen als student-assistent heb ik veel nieuwe dingen geleerd op het gebied van code uitleggen. Zo kwam ik er ook achter dat er nog veel dingen zijn die ik moet leren binnen coderen, en dat, hoewel ik de code misschien goed snap, het uitleggen van code aan mensen die het minder goed snappen toch nog best een uitdaging kan zijn. Normaal vertel je het tijdens een mondeling aan docenten die veel meer ervaring hebben met code, en nu kwamen studenten naar me toe met vragen over code. Dit was voor mij echt een hele switch die ik moest maken.

Wat ik heb geleerd

grids

Ik heb weer wat nieuws geleerd over grids, namelijk grid template areas. Dit heb ik zelf nooit gebruikt in mijn projecten en ik heb er ook nooit echt les over gehad. Ik zat samen met Maja in de les te helpen en we keken elkaar aan, omdat we dit allebei nooit hadden gehad. Dus moest ik zelf ook kort oefenen met grid areas, zodat ik het wel kon uitleggen aan de andere studenten. Ik moet zeggen dat ik grid template areas best fijn vind om te gebruiken, omdat je een grid heel specifiek kunt stylen zoals je wilt.

CSS Selector Specificity

Tijdens de minor Web hebben we het gehad over de specificity van CSS-selectors: een id gaat voor een class, en een class gaat weer voor een element. Bij Web is voor iedereen mogen studenten geen id's of classes gebruiken, dus moeten ze werken met element- en structuurselectors. Dat betekent dat selectors vaak even specifiek zijn, en dan wint de regel die het laatst in de CSS staat.

Ik hielp een student die bezig was met responsive design. De afbeelding schaalde niet goed mee: alleen de hoogte veranderde, de breedte niet. Dat kwam doordat de breedte in de mobile-first code werd aangesproken in geneste CSS. In de responsive code werd de breedte ook aangepast, maar omdat de CSS genest was, moest de selector daar net zo specifiek zijn. Daar had ik zelf geen rekening mee gehouden.

Als tijdelijke oplossing hebben we alles uit de mobile-first code gekopieerd naar de responsive code. Dat werkte, maar omdat ik zeker wist dat het simpeler kon, heb ik hem gevraagd het bij Sanne te controleren. Dat kon inderdaad: er hoefde alleen nieuwe code geschreven te worden voor de a en de img. Ook al wil je alleen de img aanpassen, je moet de responsive code op dezelfde manier genest neerzetten, anders werkt het niet.

zelf laten coderen

Een andere belangrijke les die ik heb geleerd, is dat ik ze zelf moet laten typen. In het begin wilde ik vaak voor ze typen, zodat het snel ging en ik weer verder kon. Maar in latere weken ben ik erachter gekomen dat de studenten dan niks leren. Dus nu zeg ik vaak "zoek eens op" en dan zeg ik wat ze nodig hebben. Van wat ik zie, werkt dit een stuk beter dan wanneer ik het type. Zo zien studenten nu ook sneller wanneer ze iets verkeerd hebben getypt, in plaats van dat ik het voor ze typ en hoop dat ze het snappen.

Tot slot

Voor de volgende keer zal ik de studenten meer zelf laten typen en minder voorzeggen, want tijdens het helpen ben ik erachter gekomen dat het niet helpt als ik het voor ze typ. Dan gaan ze steeds vaker vragen of ik het voor ze kan typen, en dat is niet helemaal de bedoeling. Ook zou ik actiever rondlopen en controleren of studenten echt hulp nodig hebben. Vooral in de eerste paar lessen was ik best wel terughoudend. Dit kwam ook doordat ik het zelf spannend vond, omdat mijn codeskills nu weer getest werden, maar op een heel andere manier. Code snappen is één ding, maar code zó snappen dat je het ook goed kunt uitleggen is iets heel anders. Daar wil ik zelf echt nog verder aan werken, omdat ik het een leuke uitdaging vind. Het opent mijn ogen voor hoeveel ik nog moet leren voordat ik met veel zekerheid kan zeggen dat ik alles snap binnen code.
